# nddev-mimocode-app

This public module owns the reusable MiMo Code setup manager, public contracts,
release metadata, and end-user documentation for explicit target directories.

Keep development-only tests, benchmarks, evidence, operational skills, live
runtime state, credentials, and generated caches out of this repository.

Use the manager and public contract as the source of truth for lifecycle,
profiles, locks, target layout, software pinning, and validation behavior.
Use the baseline ledger for volatile upstream release and native-surface facts.

Do not edit root nddev-harnesses, validation slices, registry metadata, other
modules, CI state, tags, or live MiMo Code configuration from this module.
